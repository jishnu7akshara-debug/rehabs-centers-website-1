How a recovery runs here

  1. 1

    Assess

    A 45-minute one-to-one with a physiotherapist: history, movement tests, strength and pain mapping.

  2. 2

    Scan if it changes the plan

    If imaging will change what we do, you walk across for an X-ray or ultrasound the same day. If not, we skip it.

  3. 3

    Treat

    Manual therapy, guided exercise and electrotherapy where it helps, in sessions of 40 minutes.

  4. 4

    Return to normal

    You leave with a home program on WhatsApp and a re-test date, so you can see the progress in numbers.
